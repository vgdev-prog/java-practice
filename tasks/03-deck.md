# 3. Колода карт

> Фаза A — основи: один клас, типи, контракти.

## Постановка

Змоделювати стандартну колоду з 52 карт. Колоду можна перетасувати, брати з неї верхню карту, роздавати руку з N карт і питати, скільки карт лишилось.

## Сутності та відповідальність

- **Масть** — фіксований перелік із 4 значень (чирва, бубна, хрест, піка).
- **Ранг** — фіксований перелік із 13 значень (двійка … десятка, валет, дама, король, туз).
- **Карта** — незмінний носій: масть + ранг. Вміє повернути свою числову вагу (туз = 14, король = 13, дама = 12, валет = 11, решта — за номіналом).
- **Колода** — головний клас. Усередині тримає карти у структурі, яка працює як стек (брати зверху). Назовні: створення повної колоди, тасування, зняти верхню карту, розмір, роздати руку з N карт.

## Поведінка / вимоги

- При створенні колода містить рівно 52 унікальні карти — усі комбінації масті й рангу.
- 52 карти генеруються **вкладеним циклом** по всіх мастях і всередині — по всіх рангах (не виписувати руками).
- Тасування перемішує карти випадково (скористатись стандартним `Collections.shuffle`, не винаходити свій алгоритм).
- Зняти карту з порожньої колоди → кинути `NoSuchElementException`.
- Роздати руку з N карт — зняти N верхніх; розмір колоди відповідно зменшується.

## Що тренує

Переліки з методами (вага карти живе в самому ранзі/карті), незмінні носії, структуру-стек (`Deque`), генерацію даних циклом замість копіпасти.

## Acceptance criteria

- 52 карти створюються вкладеним циклом по мастях і рангах.
- Тасування — через `Collections.shuffle`.
- Зняти карту з порожньої колоди → `NoSuchElementException`.

## Очікувана поведінка (приклад)

```
new Deck()        → розмір 52
shuffle()         → той самий набір, інший порядок
dealHand(5)       → 5 карт, розмір став 47
size()            → 47
```
