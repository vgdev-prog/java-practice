# 19. Парсер арифметичних виразів

> Фаза E — сучасна Java та великий домен.

## Постановка

Побудувати об'єктну модель арифметичного виразу. Вираз — це або число, або бінарна операція над двома операндами, кожен з яких **теж вираз** (рекурсія). Зібрати, наприклад, `(2 + 3) * 4` з об'єктів, обчислити значення й вивести у зрозумілому вигляді з дужками.

## Сутності та відповідальність

- **Контракт виразу** — інтерфейс із двома методами: обчислити значення; повернути «гарний» рядок (наприклад, `"(2 + 3) * 4"`).
- **Константа** — найпростіший вираз: тримає число, обчислюється сама в себе.
- **Оператор** — фіксований перелік (плюс, мінус, множення, ділення), кожне значення вміє застосувати себе до двох чисел (поведінка живе в самому переліку).
- **Бінарна операція** — вираз із трьох частин: лівий операнд-вираз, оператор, правий операнд-вираз. Обчислення **рекурсивно** обчислює лівий і правий, потім застосовує оператор.

## Поведінка / вимоги

- Обчислення бінарної операції рекурсивно викликає обчислення лівого й правого піддерев.
- Ділення на нуль → `ArithmeticException`.
- «Гарний» рядок коректно розставляє дужки навколо вкладених операцій.
- Усі обчислення — на `BigDecimal`.

## Що тренує

Composite pattern, рекурсивну композицію (дерево виразу), перелік із поведінкою.

## Acceptance criteria

- Обчислення бінарної операції рекурсивне (лівий і правий — теж вирази).
- Ділення на нуль кидає `ArithmeticException`.
- «Гарний» вивід коректно ставить дужки.

## Очікувана поведінка (приклад)

```
вираз: (2 + 3) * 4
pretty → "(2 + 3) * 4"
eval   → 20
```
